# POS releases

Installers and update files for the POS desktop app. The source code lives in a private repository; this one only holds the files a shop needs.

- **Windows**: download `POS-<version>-setup.exe` from the [latest release](https://github.com/zawibuttar/POS-releases/releases/latest) and run it.
- **Intel Mac**: `POS-<version>-x64.dmg`. **Apple Silicon Mac**: `POS-<version>-arm64.dmg`.

Installed copies check this repository for updates and offer them in Settings › About.

Read the [user guide](USER-GUIDE.md) for setup, selling, backups and Google backup.
